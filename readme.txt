# Баянхонгор JOB — эхний загвар

Энэ багц нь утас болон компьютерийн хөтөч дээр нээгдэх туршилтын вэб загвар юм.

## Ажиллуулах
1. `index.html` файлыг хөтөчөөр нээнэ.
2. Ажлын зар хайж, сум сонгож шүүнэ.
3. Баруун талын маягтаар зар оруулна.

## Анхаарах зүйл
- Зарууд Netlify Database (Postgres) онлайн санд хадгалагдаж, бүх зочдод харагдана. (Өмнө нь зөвхөн тухайн төхөөрөмжийн localStorage-д хадгалагддаг байсан.)
- Бодит онлайн үйлчилгээ болгохын тулд сервер/API, онлайн өгөгдлийн сан, хэрэглэгчийн бүртгэл, админ баталгаажуулалт, хамгаалалт, нууцлалын бодлого шаардлагатай.
- Android APK хараахан үүсгээгүй. Вэб хувилбарыг бодит backend-тэй болгосны дараа Android апп болгон багцалж болно.
- Жишээ зарууд нь зөвхөн загвар харуулах зориулалттай.

## Админ тохиргоо
1. Netlify самбар → Project configuration → Environment variables руу орно.
2. `ADMIN_PASSWORD` нэртэй хувьсагч нэмж, хүчтэй нууц үг оруулна (Secret гэж тэмдэглэнэ).
3. Сайтаа дахин deploy хийнэ.
4. Сайтын баруун талын “🔐 Админ” хэсэгт нууц үгээ оруулж нэвтэрвэл зар бүрд “Устгах” товч гарч ирнэ.

## Техник бүтэц
- `index.html` — вэб хуудас
- `netlify/functions/jobs.ts` — API (`/api/jobs`, `/api/jobs/:id`, `/api/admin`)
- `db/schema.ts` — өгөгдлийн сангийн хүснэгт
- `netlify/database/migrations/` — deploy хийх үед автоматаар хэрэгжих migration
